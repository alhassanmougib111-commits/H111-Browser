# H111 Browser - Legacy Edition
The browser that brings old iPhones back to life.

Safari on iPhone 6 (iOS 12.5) can't open Facebook - H111 can.

### Tested and Working Sites on iPhone 6 iOS 12.5
✅ Facebook - fully working
✅ YouTube - videos playing
✅ Instagram - feed and stories
✅ ChatGPT - chatting normally
✅ Gemini - working
✅ Google Search
✅ Twitter / X

### Compatibility
- iPhone: iOS 9 to iOS 18
- Mac: macOS 10.15.1 to macOS 15
- Tested device: iPhone 6 (2014) - perfect

### Features
- Tabs support
- History
- New Tab Page synced with Mac
- iOS 6 style - super fast
- Lighter than Safari and Chrome
